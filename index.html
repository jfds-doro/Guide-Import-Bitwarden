Importer vos mots de passe dans Bitwarden

Ce guide vous explique, étape par étape, comment transférer vos mots de passe vers Bitwarden — quelle que soit la méthode utilisée — et quels formats de fichiers sont acceptés.

1 Avant de commencer

L'import permet de transférer d'un coup tous vos identifiants depuis un autre gestionnaire de mots de passe (ou depuis votre navigateur) vers Bitwarden, sans les ressaisir un par un.

Le principe est toujours le même :

  1. Vous exportez vos données depuis votre ancien outil (navigateur, autre gestionnaire…) sous forme de fichier.
  2. Vous importez ce fichier dans Bitwarden.
  3. Vous supprimez le fichier d'export une fois l'opération terminée.
Bon à savoir Vos données sont chiffrées sur votre appareil avant d'être envoyées vers les serveurs Bitwarden. Personne d'autre que vous n'y a accès.
Attention aux doublons L'import ne vérifie pas si un élément existe déjà. Si vous importez deux fois le même fichier, ou des éléments déjà présents, ils seront créés en double.

2 Les méthodes d'import

Choisissez l'onglet correspondant à l'endroit d'où vous souhaitez faire l'import. La méthode la plus simple pour la plupart des usagers est l'application web.

Depuis l'application web (recommandé)

Connectez-vous à votre coffre sur vault.bitwarden.com, puis :

  1. Cliquez sur Outils (Tools).
  2. Cliquez sur Importer des données (Import).
  3. Dans le menu Coffre, choisissez la destination :
    • Mon coffre pour vos données personnelles. Vous pouvez éventuellement choisir un dossier pour ranger les éléments.
    • Le nom d'une organisation si vous importez dans un coffre partagé (nécessite la permission adéquate).
  4. Dans le menu Format de fichier, sélectionnez le format de votre fichier exporté (voir la liste des formats).
  5. Fournissez vos données de l'une de ces deux façons :
    • Cliquez sur Choisir un fichier et sélectionnez le fichier exporté ;
    • ou copiez-collez le contenu du fichier dans la zone de texte.
  6. Cliquez sur Importer. S'il s'agit d'un fichier .json protégé par mot de passe, saisissez ce mot de passe dans la fenêtre qui apparaît.
  7. Une fois l'import terminé, supprimez le fichier exporté de votre ordinateur.

Depuis l'extension navigateur

  1. Ouvrez l'extension et allez dans Paramètres (Settings).
  2. Cliquez sur Options du coffre (Vault options).
  3. Cliquez sur Importer des éléments (Import items). Une nouvelle fenêtre s'ouvre.
  4. Dans le menu Coffre, choisissez la destination (Mon coffre, éventuellement un dossier, ou une organisation).
  5. Dans le menu Format de fichier, sélectionnez le format de votre fichier.
  6. Cliquez sur Choisir un fichier et sélectionnez-le, ou copiez-collez son contenu dans la zone de texte.
  7. Cliquez sur Importer les données. Pour un .json protégé, saisissez le mot de passe demandé.
  8. Une fois terminé, supprimez le fichier exporté.

Depuis un mobile

Il existe deux façons d'importer sur mobile.

Méthode la plus courante

Sur la plupart des appareils, le plus simple est d'ouvrir un navigateur mobile, de vous connecter à Bitwarden et de suivre les étapes de l'application web ci-dessus.

Import direct via le protocole CXP

Bitwarden prend en charge le protocole Credential Exchange (CXP), qui permet un transfert direct sans passer par un fichier — à condition que l'autre application le supporte aussi.

Sur iOS 26 ou plus récent :

  1. Ouvrez l'autre application (celle où sont vos mots de passe) compatible CXP.
  2. Trouvez l'option d'export et choisissez les éléments à transférer. Exemple avec l'app Apple Mots de passe : icône Options → Exporter les données vers une autre app → cochez les éléments → Continuer.
  3. Sur l'écran Exporter les mots de passe, touchez Continuer.
  4. Choisissez Bitwarden comme destination, puis Continuer.
  5. Touchez Continuer dans « Bitwarden ».
  6. L'app Bitwarden s'ouvre : touchez Continuer pour confirmer l'import.

Sur Android 10 ou plus récent :

  1. Ouvrez l'application Bitwarden.
  2. Touchez Paramètres → Coffre → Importer des éléments.
  3. Touchez Importer depuis une autre app.
  4. Sélectionnez l'autre application compatible CXP, puis Continuer.
  5. Choisissez les éléments à importer (une connexion peut être demandée).
  6. Un message confirme la fin de l'import.
Remarque Pour l'instant, l'import des données Dashlane via CXP n'est pas pris en charge sur Android.

Depuis l'application bureau

  1. Sélectionnez Importer dans le menu de navigation.
  2. Dans le menu Coffre, choisissez la destination (Mon coffre, éventuellement un dossier, ou une organisation).
  3. Dans le menu Format de fichier, sélectionnez le format de votre fichier.
  4. Cliquez sur Choisir un fichier et sélectionnez-le, ou copiez-collez son contenu dans la zone de texte.
  5. Cliquez sur Importer les données. Pour un .json protégé, saisissez le mot de passe demandé.
  6. Une fois terminé, supprimez le fichier exporté de votre appareil.

Depuis la ligne de commande (CLI)

Pour les utilisateurs avancés, la commande est :

bw import <format> <chemin_du_fichier>

La commande a besoin d'un format et d'un chemin. Pour obtenir la liste des formats disponibles :

bw import --formats

Exemple concret :

bw import lastpasscsv /Users/moncompte/Documents/mesdonnees.csv

Une fois l'import terminé, supprimez le fichier exporté.

3 Formats de fichiers acceptés

Bitwarden accepte directement les formats ci-dessous. Utilisez la barre de recherche pour trouver rapidement votre ancien outil.

Votre outil n'est pas listé ? Tant qu'il permet d'exporter vos données, vous pouvez adapter le fichier au format Bitwarden (.csv ou .json) puis l'importer.

Aucun outil ne correspond à votre recherche.

4 En cas d'erreur d'import

Si une limite est dépassée ou si le fichier contient un problème, un message « Erreur d'import » apparaît. Dans ce cas, aucune donnée n'est ajoutée à votre coffre.

Limites de taille d'un fichier

Un fichier importé peut contenir au maximum :

  • 40 000 éléments
  • 2 000 dossiers
  • 2 000 collections
  • 7 000 relations élément-dossier
  • 80 000 relations élément-collection

Si votre fichier est trop volumineux, découpez-le en plusieurs fichiers plus petits et importez-les séparément.

Champ trop long

Si un champ d'un élément (souvent dans un .csv) dépasse la limite de caractères, l'élément n'est pas importé. Le message d'erreur précise l'élément et le champ concernés.

Pourquoi ? Le chiffrement de Bitwarden augmente la taille du texte de 30 à 50 %. Un champ « Notes » de 8 000 caractères peut ainsi dépasser la limite de 10 000 caractères une fois chiffré. Réduisez alors le texte concerné, enregistrez le fichier et réimportez-le.

Éléments non assignés (organisations)

Dans une organisation, les membres (hors administrateurs et propriétaires) doivent assigner chaque identifiant importé à au moins une collection. Assignez une collection existante sur laquelle vous avez les droits, ou créez-en une nouvelle directement dans le fichier d'import.

5 Après l'import — le réflexe sécurité

  1. Vérifiez que vos identifiants sont bien présents dans votre coffre Bitwarden.
  2. Supprimez le fichier exporté de votre ordinateur ou de votre appareil. Ce fichier contient vos mots de passe en clair : le conserver serait un risque en cas de compromission de votre poste.
  3. Videz les mots de passe de l'ancien outil (navigateur ou ancien gestionnaire) une fois que vous avez confirmé que tout est bien dans Bitwarden.
Ne gardez jamais un fichier d'export de mots de passe C'est un fichier lisible par n'importe qui. Videz aussi la corbeille après suppression.
